
## OCR Invoice Processing System

Category:
AI / OCR

Description:
Abhishek is developing an AI-powered invoice processing system that extracts information from invoice and receipt images and converts the OCR output into structured data.
priority:3
Technologies:

Python
FastAPI
PaddleOCR
SQLAlchemy
MySQL
PostgreSQL
Supabase

Features:

Invoice image upload
OCR
Text extraction
Structured data extraction
Invoice storage
REST API

The backend is built using FastAPI.

The project explores migrating the database from MySQL to Supabase PostgreSQL.
